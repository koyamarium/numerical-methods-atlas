# 時間依存テスト：動画と保存状態

[動画ギャラリーを開く](#/movies)。

衝撃波反射、渦の移流、磁場形成など、時間発展自体が問いに含まれる場合に動画を使います。定常解、製造平衡分布、最終楕円場は静止図のままです。反復に対する残差はアルゴリズムの履歴で、物理時間の流体動画ではありません。

## 計算した5つの動画 {#five-computed-movies}

- **二重Mach反射**：256×64セルのMach 10・2次元Euler、t=0〜0.2、1次HLL、SSPRK2、CFL0.4。細い壁面ジェットは未解像です。[設定](double-mach.md)を参照してください。
- **CTのOrszag–Tang**：64²の周期平面理想MHD、t=0〜0.5、1次Rusanov、前進Euler、CFL0.3。磁場発散はスタガード面演算子です。
- **GLMのOrszag–Tang**：同じ解像度・物理区間、クリーニング速度3、減衰0.18を固定。発散はセル中心の中心差分です。CT／GLM図は同一精度の順位ではありません。[MHD定義](mhd.md)を参照してください。
- **原型KEEPの滑らかな等エントロピー渦**：[−10,10]²の96²周期Euler、t=0〜4、2次算術平均直交KEEPと古典的RK4、CFL0.25。衝撃波安定化、圧力平衡拡張、厳密エントロピー保証は含みません。[KEEPの章](keep.md)を参照してください。

- **Mach 3前向きステップ**：240 × 80セル、t=0〜4、1次HLL・SSPRK2、CFL 0.4。x=0.6から高さ0.2の段差を、格子面に一致する障害物セルで表します。通常の反射境界で、角のエントロピー・エンタルピー再設定は行いません。診断から固体セルを除きます。古典的な非粘性テストであり、NASA実験の妥当性確認ではありません。[衝撃波問題の定義](nasa-2d.md)を参照してください。

毎動画に密度と圧力を併記します。リポジトリのソルバーの数値状態から描いたもので、補間した模式図や原論文動画の再現ではありません。

## 実際の物理時刻と不変の時間刻み {#actual-physical-times-unchanged-time-steps}

初期・最終を含む81出力時刻を要求し、それぞれを最初に通過した完了計算状態を保存します。要求時刻へ合わせるための刻み短縮も、解の補間も**しません**。粗い1ステップが複数要求を越えれば同じ状態が代表します。全フレームに実時刻とステップ数を付けます。

公開用動画は各81の異なる状態です。CT・GLMは時間刻みが違うため、同じフレーム番号でも途中の物理時刻は一致しない場合があります。比較前に時刻を確認してください。出力を有効にしても最終状態・数値履歴が不変であることをテストします。

## 固定色範囲と明示的な再生 {#fixed-scales-and-explicit-playback}

密度・圧力の色範囲は、各計算の全保存状態の最小・最大で固定します。範囲ラベルが一致しない限り、別動画の同じ色を同じ値と見なしてはいけません。プレーヤー横の最小・最大は表示状態の実測値で、正値性定理ではありません。

**再生**を押すまで始まりません。一時停止、先頭・末尾、前後、保存フレームスライダー、速度、任意のループで検査できます。速度は表示速度で、シミュレーションを変えません。標準12fpsなら81フレームは6.75秒です。物理時刻は画像内にも残します。

通常のMP4プレーヤーとMP4・フレーム保存も使えます。MP4は音声なしH.264、検査画像は可逆WebPです。圧縮は表示処理で、計算へ戻りません。

## 再現と検証 {#reproduce-and-verify}

```bash
python -m pip install '.[movies]'
python scripts/build_movies.py
python scripts/check_movies.py
```

ビルダーは公開フレーム、MP4、[動画カタログ](https://koyamarium.github.io/numerical-methods-atlas/assets/movies/catalog.json)を`website/public/assets/movies`へ保存します。完全な数値スナップショットも、Git対象外の`outputs/movies`へ圧縮NumPy配列で保存します。カタログにはソース・画像・動画・数値状態のハッシュ、ソフトウェア版、手法、境界、物理尺度、各フレーム診断があります。

検査ではハッシュ・メタデータを確認し、各画像を開き、MP4を復号して寸法、再生率、全フレーム数を検証します。`--quick --output <directory>`は小格子の短い検査で、カタログにも区別し、公開用の本計算とはしません。

## 多次元の場を示す静止図 {#multidimensional-still-fields}

[数値ギャラリー](#/gallery)は2D・3Dの空間場を先頭に表示し、上記5動画への入口もまとめています。次元と分野の絞り込みを組み合わせられます。「全次元・診断図」では1次元比較とアルゴリズムの診断図も表示します。

既存ソルバーから、次の3つの場の静止図を追加しました。

- **2次元三角形P1 Poisson**：24 × 24の正方形を分割した1152三角形、ゼロDirichlet境界、厳密解sin(πx)sin(πy)。第2パネルは節点誤差で、連続的なL2・H1誤差は要素内部で別に測ります。
- **2次元周期Taylor–Green**：64 × 64 MACセル、粘性0.1、t=0.5。速さ・矢印の表示だけ面速度をセル中心へ平均し、速度RMS・発散の診断には元のMAC配列を使います。
- **3次元周期Poisson**：32³のFFT計算、密度1 + 0.3 cos(2πx)cos(4πy)cos(2πz)、G=1、平均ゼロのポテンシャル。各座標0.5の直交3断面を共通の色範囲で示します。一つの厳密Fourierモードと照合した静的な3次元場で、3次元流体や粒子の時間発展ではありません。

`python scripts/build_multidimensional_gallery.py`で再現できます。[定義・診断量・ソースハッシュ](figures/multidimensional-fields.json)と[計算配列](figures/multidimensional-fields.npz)をダウンロードできます。新しいソルバーや収束実験を追加したわけではなく、既存のFEM・MACの細分化検査は別の検証です。

5本目の動画は`python scripts/build_shock_gallery.py`で作成し、独立した[衝撃波動画カタログ](https://koyamarium.github.io/numerical-methods-atlas/assets/movies/shock-catalog.json)に記録します。プレーヤーは両方のカタログを統合します。完全な保存状態は`outputs/shock-gallery`にあります。

## 動画だけでは示せないこと {#what-a-movie-does-not-establish}

滑らかな見た目だけでは、格子収束、エントロピー不等式、衝撃波の頑健性、長時間乱流精度、実験一致は示せません。[KEEP渦の収束](keep.md)には独立した滑らか誤差の測定があり、[カーバンクルの章](carbuncle.md)は衝撃波動画だけで多次元安定性を保証できない理由を説明します。


## 再構成の比較動画 {#reconstruction-comparison-clips}

[Euler比較ページ](#/flow-comparison?case=forward-step&method=mc)では、同じ前向きステップ問題について1次・minmod・MCの動画を並べ、共通の色範囲と各81出力状態で比較できます。適応時間刻みの途中時刻は完全には一致しないため、フレーム内の実際の時刻を確認してください。再構成の比較であり、5物理問題の動画カタログの問題数は増えません。`python scripts/build_euler_comparison.py`で生成し、各MP4を復号してフレーム数を確認します。
